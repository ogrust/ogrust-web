There is a curated list of issues using the tag `C3-og-rust-bounty` on both the [`polkadot-sdk`](https://github.com/paritytech/polkadot-sdk/issues?q=state:open%20label:C3-og-rust-bounty) and [`runtimes`](https://github.com/polkadot-fellows/runtimes/pulls?q=is:open+is:pr+label:C3-og-rust-bounty) repositories.

You can also find issues of various sizes in the `polkadot-sdk` wishlists: [Wishlist: Users](https://github.com/paritytech/polkadot-sdk/issues/3901) and [Wishlist: Developers](https://github.com/paritytech/polkadot-sdk/issues/3900) which may be good candidates for a bounty proposal.
